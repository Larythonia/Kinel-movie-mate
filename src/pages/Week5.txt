Q1- What is useEffect used for? Explain what the dependency array does — what happens when you pass [] vs [userId] vs nothing at all? Write a useEffect that fetches a list of movies from an API URL when the component first loads.

ANS
useEffect is a React hook used to perforrm side effects usually outside the render cycle which includes; fetching data(API), subscriptions, setting timers, updating the DOM and listening to events.

The dependency array is the second useEffect's argument that tells React when to re-run or re-render the effect.
When you pass an empty array [], the componenents runs only when it firdt loads
When you have values in an array e.g [userId], it runs on first render and when the userId changes.
No array runs after every render.

  Q2 -Explain the race condition problem in useEffect. If a user types quickly and multiple fetch requests fire, what goes wrong without a fix? Write the 'cancelled flag' solution that prevents setting state from a stale request, including the cleanup function.

  ANS
  A race condition happens when the correctness of your program depends on the order or timing of independent events, and that order is not guaranteed.The name comes from the idea that two or more processes are "racing" to finish, and the wrong one winning causes a bug.

  The slowest respond will win, not the fastest. 
  Example;
  User types "react"
→ 4 fetches fire: "r", "re", "rea", "react"
→ "react" responds first ✅ → UI shows react results
→ "r" responds last   💥 → UI overwrites with r results
The user typed "react" but sees results for "r" — because there's nothing controlling which response gets to call setResults last.
